DOU-Synapse API

Ders materyaline bağlı, kaynaklı cevap üreten ders asistanının HTTP yüzeyi. Her cevap dayandığı sayfayla döner; dayanak yoksa uç cevap değil gerekçeli ret döndürür. Ders izolasyonu iki katmanda zorlanır: sunucu tarafında üyelik doğrulaması ve aynı oturumda PostgreSQL satır düzeyi güvenlik.

  • ŞemaOpenAPI 3.1
  • KimlikBearer (Supabase JWT)
  • Hata zarfıerror.code · message · request_id
  • Sayfalamaitems + next_cursor
